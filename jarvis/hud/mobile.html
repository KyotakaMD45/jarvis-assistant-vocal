Utiliser Apex avec Siri
  1. App Raccourcis > +, ajoutez Dicter du texte.
  2. Ajoutez Obtenir le contenu de l'URL : collez l'adresse ci-dessous, méthode POST, corps JSON avec un champ text = Texte dicté.
  3. Ajoutez Obtenir la valeur du dictionnaire (clé reply), puis Énoncer le texte.
  4. Nommez le raccourci Apex, puis dites « Dis Siri, Apex ».
