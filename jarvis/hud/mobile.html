Utiliser Apex avec Siri
  1. Ouvrez l'app Raccourcis > +.
  2. Ajoutez l'action Dicter du texte.
  3. Ajoutez Obtenir le contenu de l'URL : collez l'adresse ci-dessous, méthode POST, corps de requête JSON avec un champ text = Texte dicté.
  4. Ajoutez Obtenir la valeur du dictionnaire : clé reply.
  5. Ajoutez Énoncer le texte, puis nommez le raccourci Apex.
Ensuite : « Dis Siri, Apex » (le téléphone doit être sur le même Wi-Fi que le PC). —
